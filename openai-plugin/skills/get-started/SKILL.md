# Getting started with Convocore

1. List the user's agents. If there are none, offer to create one from their business website.
2. For an existing agent, offer to: summarize its recent conversations, add pages to its knowledge base,
   or test it with a sample question.
3. Ask before anything that deletes data, sends a message or places a call.
4. Plans, phone numbers and payments are managed on the Convocore dashboard (https://convocore.ai), not here.
